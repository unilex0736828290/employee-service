
# Employee Service Microservice

## 📌 Overview
This is a Spring Boot microservice responsible for managing employee data.

## 🚀 Tech Stack
- Java 17
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- REST APIs
- Git & GitHub (SSH)

## 📂 Features
- Create employee
- Update employee
- Delete employee
- Fetch employee details

## 🛠 How to Run
1. Clone the repository
2. Configure MySQL in application.properties
3. Run using:
   mvn spring-boot:run
